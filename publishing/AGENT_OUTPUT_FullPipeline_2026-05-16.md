2. ก่อนซื้อประกันสุขภาพ อย่าดูแค่เบี้ย ดู “ค่ารักษาที่เรารับเองไหว” ก่อน
3. Co-payment ไม่ได้น่ากลัวถ้าเข้าใจ แต่ถ้าไม่อ่านเงื่อนไข อาจเจ็บตอนเคลม
4. มีประกันกลุ่มแล้ว ยังต้องซื้อเพิ่มไหม?
5. OPD คุ้มไหม ถ้าเราไม่ได้หาหมอบ่อย?

### Share Prompt

แชร์เก็บไว้ก่อนตัดสินใจซื้อประกันสุขภาพครับ โดยเฉพาะคนที่มีประกันกลุ่มอยู่แล้ว แต่อยากรู้ว่าวงเงินพอไหม

## 8) ADS TARGETING IDEA

### Campaign Objective

เริ่มจาก Traffic หรือ Engagement ไปบทความก่อน แล้ว retarget คนที่อ่าน/คลิก/ดูวิดีโอไป LINE OA

หากต้องการ lead เร็ว:

- ใช้ Messages objective
- CTA: ทัก LINE OA / ส่งข้อความ

### Audience Test Set

Ad Set A: Working Family 28-45

- อายุ: 28-45
- พื้นที่: หาดใหญ่, สงขลา, ภูเก็ต, กรุงเทพฯ, เชียงใหม่, ชลบุรี, ระยอง หรือเมืองที่มีโรงพยาบาลเอกชนเด่น
- Interest: ประกันสุขภาพ, โรงพยาบาลเอกชน, วางแผนการเงิน, สุขภาพครอบครัว, การเงินส่วนบุคคล

Ad Set B: Parents / Family Planner

- อายุ: 30-50
- สนใจ: ครอบครัว, ลูก, การศึกษา, สุขภาพเด็ก, ประกันชีวิต, วางแผนครอบครัว
- Message angle: "ถ้าคนหาเงินหลักป่วยหนัก แผนครอบครัวสะดุดไหม"

Ad Set C: OPD Concern

- อายุ: 25-40
- สนใจ: health checkup, private hospital, wellness, fitness, ประกันสุขภาพ
- Message angle: "OPD คุ้มไหม ถ้าไม่ได้หาหมอบ่อย"

### Exclusion

- ตัวแทนประกัน/นายหน้าประกัน ถ้า campaign ต้องการลูกค้าใหม่
- คน engage ต่ำซ้ำๆ ใน 30 วัน
- คนที่คอมเมนต์เชิงถกเถียงแต่ไม่ใช่ prospect หากงบจำกัด

### Budget Test

- เริ่ม 300-500 บาท/วัน ต่อ ad set
- ทดสอบ 3-5 วัน
- ดู CTR, CPC, watch time, comment quality, LINE OA inquiry quality

### Creative Testing Plan

Test A: Hook ตัวเลข

> ค่ารักษา 200,000 คุณจ่ายเองกี่บาท?

Test B: Hook ความเข้าใจผิด

> หลายคนเลือกประกันสุขภาพผิด เพราะเริ่มจากวงเงิน ไม่ใช่ความเสี่ยง

Test C: Hook Co-payment

> เห็นข่าว Co-payment แล้วควรกลัว หรือควรเข้าใจก่อน?

## 10) FINAL RECOMMENDATION

บทความวันนี้ใช้เป็น flagship article สำหรับเริ่ม SEO ได้ดี เพราะครอบคลุมทั้งความกังวลเรื่องค่ารักษา, Co-payment, OPD/IPD, ประกันกลุ่ม และการคุยกับตัวแทนแบบไม่ hard sell

5. เพิ่ม UI checklist ในเว็บเพื่อให้คนอ่านมีส่วนร่วมและทัก LINE OA ง่ายขึ้น
